# Contribution & External Submission Policy

AETHER X Governed Intelligence is a **public technology showcase**, not an open-source implementation repository.

## External implementation contributions

AETHER X GLOBAL is not currently requesting external source-code, SDK, validator, schema, algorithm or implementation contributions through this repository.

Do not submit:

- confidential or proprietary information;
- trade secrets;
- third-party source code you are not authorized to disclose;
- customer or personal data;
- credentials or security-sensitive material;
- unpublished inventions or research intended to remain confidential;
- material governed by an NDA or other restriction that does not permit public disclosure.

## Public corrections

Factual corrections to public documentation may be raised through an appropriate public issue or pull request at AETHER X's discretion, provided the submission contains no confidential or restricted information.

Submission of an issue, pull request, comment or other material does not create an NDA, evaluation agreement, commercial licence, partnership, employment relationship or right to access non-public AETHER X technology.

Because this repository does not publish an open-source licence, contributors should not assume that a conventional open-source contribution model applies.

## Enterprise evaluation

Organizations seeking technical diligence, evaluation, licensing or strategic collaboration should use the **Enterprise Evaluation Request** issue form and provide only non-confidential introductory information. Deeper technical engagement follows the controlled disclosure process described in `docs/ENTERPRISE_EVALUATION.md`.

## Security

Do not publish sensitive vulnerability details in a public issue or pull request. Follow `SECURITY.md`.

---

**AETHER X GLOBAL reserves the right to close, decline or redirect submissions that fall outside the purpose of this public technology surface.**
