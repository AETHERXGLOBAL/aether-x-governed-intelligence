## Snapshot Semantics

A snapshot records:

- an immutable Git commit anchor;
- the declared public artifact/version inventory at that anchor;
- Git blob identities for material files;
- selected public CI evidence available for the recorded technical series;
- explicit claim boundaries.

A snapshot does **not** mean:

- GitHub Release;
- Git tag;
- product release;
- production readiness;
- product integration;
- SDK/API stability;
- implementation inside any AETHER X portfolio initiative.

`PUBLIC SNAPSHOT ≠ PRODUCT RELEASE`

For compatibility rules, see [`AX-PUB-POL-001`](../docs/COMPATIBILITY_AND_VERSIONING.md).
